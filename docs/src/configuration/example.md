# Example configuration file

This file sets every available setting, with a comment for each. Copy it,
delete what you do not need, and pass it with `--config`. The full
explanation of each key is in the [settings reference](reference.md).

The same file is in the repository at `docs/src/configuration/filebrary.example.toml`, and
the test suite checks that it is valid, so it always matches the current
version.
