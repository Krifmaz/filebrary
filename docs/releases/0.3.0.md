## Filebrary 0.3.0

A new web UI. Every page is rebuilt on the kit, in the Encore theme, and works the same on a phone, a tablet and a desktop.

- **Files.** Details, compact and three tile sizes with thumbnails; select with Shift, Ctrl or a long press; a right-click menu (a sheet on phones); move, copy, rename and delete with Undo; drag onto a folder or the path bar to move; the trash, stars, tags, comments and collections.
- **Uploads that resume.** Drop files or whole folders. Uploads go in chunks, carry on after a dropped connection or a reload, and show a panel with pause, retry, replace and keep both.
- **Previews and the editor.** Pictures, video, sound, PDFs and text, with arrow keys or a swipe to step through, Cast where the browser can, and a text editor that checks for other people's changes before it saves.
- **Search.** By name or by the text inside files, with type, source, date, size and extension filters, sorting and highlighted matches. Every search is a link you can share.
- **Share links.** A Shared page that cleans up dead links in one go, a share dialog with expiry presets and drop links, and a public page with a password prompt, folder browsing, previews and drop uploads that resume.
- **Settings and administration.** Account, security, preferences and appearance; users, groups, permissions per source, jobs and the search index, and branding.
- **Works offline.** The app opens with no connection, and stars you set while the server can't be reached are sent once it's back.
- **From the kit.** This What's new, bug reports with crash logs, Diagnostics and server settings for admins, notice banners, toasts with Copy, and an update prompt that waits for your uploads and unsaved edits.
- **Themes.** Encore, dark, black for OLED screens, light, or follow the device. The old custom colour palettes are gone.
